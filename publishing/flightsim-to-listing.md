# Flightsim.to Publication Pack — NaviXav

Everything needed to publish or update the NaviXav listing on Flightsim.to,
**except the texts themselves**. This file holds only the fields, the files and
the checklist; each block of copy lives in exactly one place and is pasted from
there.

| Flightsim.to field | Paste from | Format |
| --- | --- | --- |
| Description | [flightsim-to-description.txt](flightsim-to-description.txt) | Plain text, emoji headings, four-space bullets |
| Changelog | [flightsim-to-changelog.txt](flightsim-to-changelog.txt) | Whole file, regenerated by `prepare_release.ps1` |
| Short summary, title, tags | this file | — |

Nothing else is duplicated here. Product facts belong to
[README.md](../README.md); pending user-visible changes, in the eight interface
languages, belong to [RELEASE_HIGHLIGHTS.json](../RELEASE_HIGHLIGHTS.json).

This pack is not itself a claim that pending source changes have shipped: the
version you enter is the one released, read from `navixav/__init__.py`.

## Listing details

### Title

NaviXav – IFR Flight Planning and Live Flight Assistant

### Category

Utilities / Miscellaneous

### Simulator compatibility

Microsoft Flight Simulator 2024 only. MSFS 2020 must not be selected: NaviXav
uses the native MSFS 2024 SimConnect AI EX1 API and rejects an MSFS 2020 DLL at
startup.

### Version

The version being released, as set in `navixav/__init__.py`.

### Release status

Freeware, under the PolyForm Noncommercial License 1.0.0: the source is public,
noncommercial use is free and commercial use requires a separate written
licence. Nothing is locked behind a payment. Releases tagged v1.4.12 and
earlier remain under Apache 2.0 — never describe the current code that way.

### Short summary

> Stop juggling windows and start flying. NaviXav is a lightning-fast, native
> Windows dashboard for MSFS 2024 that seamlessly bridges the gap between your
> SimBrief OFP and your cockpit. Moving map, live flight tracking, weather and
> dispatch briefings, a game-changing readable taxi guidance system — and live
> traffic around you from VATSIM, IVAO or OpenSky, displayed on the map and
> injected straight into the simulator with your FSLTL or AIG models. No cloud
> delays, no subscription paywalls, source available to everyone — just
> local-first, pilot-centric execution that lets you focus on what matters: the
> flight.

## Files to upload

Both files are complete and usable independently. Never upload checksum files
as separate download options.

**Primary** — `NaviXav-<version>-FlightsimTo-Installer.zip`

Label: `Recommended Windows Installer`

Description: `Recommended installation for Windows 10/11 64-bit. Includes the
NaviXav setup program and installation notes. Do not install in the MSFS
Community folder.`

**Secondary (optional)** — `NaviXav-<version>-windows-x64-portable.zip`

Label: `Portable Version`

Description: `Portable Windows version. Extract the complete archive and run
NaviXav.exe. Microsoft Edge WebView2 Runtime must already be installed.`

## Upload checklist

- [ ] Use the title exactly as written above and preserve title case.
- [ ] Select **Utilities / Miscellaneous**.
- [ ] Select **Microsoft Flight Simulator 2024** only.
- [ ] Set the version to the one in `navixav/__init__.py`.
- [ ] Upload the installer ZIP as the primary file.
- [ ] Optionally upload the portable ZIP as a secondary independent file.
- [ ] Paste the description from `flightsim-to-description.txt`, unedited —
      including the flight-simulation warning and the licence section.
- [ ] Paste the whole of `flightsim-to-changelog.txt` into the changelog field.
- [ ] Check that the short summary above still matches what the release does.
- [ ] Add at least two original screenshots of 512 × 512 px or larger.
- [ ] Add a clear thumbnail without clickbait wording.
- [ ] Scan every uploaded archive with VirusTotal and record the result. A lone
      generic machine-learning verdict on an unsigned build is expected; submit
      it to the vendor rather than blocking the release.
- [ ] Confirm each ZIP extracts and launches on a clean Windows user account.
- [ ] Confirm `LICENSE`, `COMMERCIAL_LICENSE.md`, `NOTICE`,
      `THIRD_PARTY_NOTICES` and the bundled third-party licence texts ship.
- [ ] Do not add an external download link to the Flightsim.to description.
- [ ] Do not create a new listing for a new version: update this one through
      its Versioning tab.
- [ ] Review Flightsim.to's current upload rules immediately before submission.
