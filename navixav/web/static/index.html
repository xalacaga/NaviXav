Trafic & modèles FSLTL Détection, modèles et injection SimConnect
Le trafic statique ne vient d’aucun réseau : NaviXav gare des appareils aux postes de stationnement que MSFS lui a donnés, avec les livrées du jeu de modèles choisi. Personne ne roule ni ne décolle.

FSLTL Base Models

Installe uniquement FSLTL Traffic Base Models avec l’installateur FlyByWire ; NaviXav n’utilise pas FSLTL Injector.

AIG AI Traffic

Installe les modèles AIG avec AI Manager ou le pack OCI ; NaviXav n’utilise pas AIG Traffic Controller. Le trafic OpenSky est réel : ce sont les avions effectivement en vol autour de toi. Leur type est résolu depuis le registre OpenSky, puis ils sont injectés dans MSFS comme les réseaux de simulation. OpenSky Network

Panneau MSFS
